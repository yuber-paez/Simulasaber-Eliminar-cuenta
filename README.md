# Eliminación de Cuenta - SimulaSaber

Para solicitar la eliminación de tu cuenta y todos los datos asociados en la aplicación **SimulaSaber**, sigue estos pasos:

1. Envía un correo electrónico a: **[santiagopc333@gmail.com]**
2. En el asunto del correo escribe: **Solicitud de eliminación de cuenta**.
3. En el mensaje, por favor incluye la dirección de correo electrónico con la que te registraste en la aplicación para poder identificarte.

**¿Qué datos se eliminarán?**
Una vez recibida la solicitud, procederemos a borrar de nuestros servidores de forma permanente:
* Tu nombre y dirección de correo electrónico.
* Tu historial de simulacros, calificaciones y progreso.
* Tu pertenencia a los grupos de estudio.

Este proceso se completará en un plazo máximo de 30 días.
